# Base de conocimiento de ejemplo

Este documento sirve para probar el flujo RAG local de Kyba.

## Información útil
- Kyba puede responder preguntas usando documentos locales.
- El backend usa Ollama como modelo local y ChromaDB para recuperar contexto.
- La respuesta final se construye a partir del contenido indexado.

## Ejemplo de pregunta
Si preguntas por la arquitectura de Kyba, la respuesta debe basarse en este documento.
