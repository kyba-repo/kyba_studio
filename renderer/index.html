Conectar Kyba a otros IDEs

Puedes usar el motor de Kyba directamente desde tu editor de código favorito (VS Code, Cursor, etc.) instalando extensiones como Continue.dev o Cline.

Compartir en Red Local (Wi-Fi)
Permite que otros dispositivos de tu red puedan conectarse a este servidor. (Requiere reiniciar kyba despues de activar esta opcion).

1. Configurar la extensión Continue

Abre el archivo de configuración en ~/.continue/config.yaml y agrega estos bloques dentro de la lista de models: 

name: Main Config
version: 1.0.0
schema: v1
models:

  # Modelo para chat
  - name: Kyba Chat
    provider: openai
    model: ministral-3:8b
    apiKey: kyba
    apiBase: http://127.0.0.1:8000/v1
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use
    defaulCompletionOptions:
      contextLenght: 256000
      maxTokens: 246000

# Modelo para autocompletado (tab completion)
  - name: Kyba Autocomplete
    provider: openai
    model: Qwen2.5-coder
    apiKey: kyba
    apiBase: http://127.0.0.1:8000/v1
    roles:
      - autocomplete
    defaulCompletionOptions:
      contextLenght: 128000
      maxTokens: 120000
